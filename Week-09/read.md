# Week 9 – Echobridge Hackathon

This week at **@Cyberster**, I worked on the **Echobridge Hackathon** project using **Cisco Packet Tracer**.

The project focused on designing a cost-effective enterprise network for **24 agents and 1 manager**, providing reliable voice communication and central server access while staying within a **1.5 Million PKR budget**.

## Technologies & Concepts

- VLAN 10 – Data
- VLAN 20 – Voice
- VLAN 30 – Server
- Router-on-a-Stick
- 802.1Q Trunking
- Inter-VLAN Routing
- Static Routing
- Voice VLAN
- IP Addressing
- Daisy-Chaining
- Network Verification

## Key Implementation

The network was divided into separate VLANs for data, voice, and servers. Router-on-a-Stick was used for inter-VLAN communication, while static routing provided connectivity between network sections.

A **Switch → IP Phone → PC** daisy-chain was used to reduce cable requirements and optimize the project cost.

## Verification

- PC-to-Gateway connectivity
- PC-to-Server connectivity
- Voice VLAN verification
- Routing verification
- End-to-End connectivity

## Learning Outcome

This project improved my practical understanding of **enterprise network design, VLAN segmentation, voice networking, routing, troubleshooting, and cost optimization**.
