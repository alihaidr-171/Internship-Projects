# Enterprise Network Design Using Static Routing

## Overview

This project was completed during **Week 05** of my **Network Security Internship at Cyberster**. The objective was to design and implement a complete enterprise-level network using Cisco Packet Tracer while applying **Static Routing** and a **hierarchical network architecture**.

The network demonstrates how enterprise environments are organized into **Core, Aggregation (Distribution), and Access** layers, providing scalable and efficient communication between multiple wired and wireless devices.

---

## Objectives

- Design a scalable enterprise network.
- Implement Static Routing between multiple routers.
- Build a hierarchical network architecture.
- Connect both wired and wireless devices.
- Verify end-to-end connectivity.
- Understand the role of each network layer.

---

## Network Architecture

The network is divided into four logical layers:

### Core Layer
- Acts as the high-speed backbone of the enterprise network.
- Connects different parts of the network together.

### Aggregation Layer
- Aggregates traffic from multiple distribution switches.
- Connects the Core Layer with the Distribution Layer.
- Forwards traffic between different network segments.

### Distribution Layer
- Connects routers to access switches.
- Manages traffic before forwarding it to the Core Layer.

### Access Layer
Provides network access to end-user devices, including:

- Desktop Computers
- Wired Laptops
- Wireless Laptops
- Mobile Phones
- Wireless Access Points
