## Week 6 – Mid-Term Enterprise Network Assignment

### Objectives
- Design a small enterprise network based on a real-world company scenario.
- Apply VLSM subnetting for efficient IP address allocation.
- Configure VLANs and Static Routing.
- Implement a hierarchical network architecture.
- Verify connectivity and routing between network segments.

### Activities
- Performed VLSM subnetting for Sales, IT, Finance, and HR departments.
- Designed the physical and logical network topology using Cisco Packet Tracer.
- Organized the network into Core, Distribution (Aggregation), and Access layers.
- Created dedicated VLANs for each department and assigned switch ports accordingly.
- Configured trunk links between switches and the main router.
- Implemented Static Routing between the main office and a remote branch router.
- Verified communication between departments using ping tests.
- Configured routing policies to ensure the IT department could access all networks while restricting Finance and HR access to the Sales department.

### Outcome
Successfully designed and configured a small enterprise network using VLSM, VLANs, and Static Routing. Gained practical experience in IP planning, network segmentation, hierarchical network design, routing configuration, and implementing communication policies between different departments.
